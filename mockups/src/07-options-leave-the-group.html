Offer to leave once the quests are done
When every quest you grouped for through the finder is done, a window offers to leave. Nothing happens without your click.
Say a message in /p before leaving
Only when you click Leave: the message goes to the party, then you leave. Never automatic.

Edit the message
Options · on the left the panel (two extra switches + the message line; “Edit…” opens the small input window below); on the right the Polestar page: the same two switches and a button that opens the same window (Polestar has no text field in its options). Defaults: the offer is on, the message is off; default text follows the client language (FR: “Merci pour le groupe, bon jeu !”, EN: “Thanks for the group, have fun!”).
